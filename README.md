Project Features
- CRUD Operations: GET, POST, PUT, PATCH and DELETE.
- Class-Based Views (CBVs): Organized API request handling.
- Serialization: Convert Django model data to JSON and validate incoming data.
- Nested Serialization: Include related user details in post responses.
- Media File Handling: Upload and serve images using Django media settings.
- REST API Responses: Return structured JSON data.
- Database Integration: Store and manage users and post records.
